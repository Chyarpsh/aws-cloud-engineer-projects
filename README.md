## 🧭 About the Folder Naming (P1, P2, P3...)

| Phase  | Description |
|--------|--------------------------|
| P1 | AWS Basics & Core Concepts |
| P2 | Networking Foundations |
| P3 | Databases & Storage |
| P4 | Cloud Security |
| P5 | Compute & Containers | 
| P6 | DevOps Foundations |
| P7 | AI + Cloud Integrations | 

To avoid confusing nested folders, each lab is stored at the root level and follows this naming format:

P# = Phase Number
Lab## = Lab Number within that phase


Example:  
`p1-lab01-host-a-website-on-amazon-s3` means:

- **p1** → Phase 1 (AWS Basics)  
- **lab01** → Lab #1 within Phase 1  
- **host-a-website-on-amazon-s3** → Short, descriptive lab topic
